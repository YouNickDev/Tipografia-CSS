Resumo de Tipografia

Tipografia é o estilo, arranjo eaparência de texto. Ela envolve a seleção de fontes, tamanhos,espaçamento e outros elementos queafetam a legibilidade e a estética dotexto.

No Arquivo CSS

        
 

     <style>
        body {
            font-family: 'Arial',sans-serif;
            font-size: clamp(1rem, 2vw, 1.5rem);
            line-height: 1.6;
            color: #333;
         }
 
        h1 {
            font-size: 2.5rem;
            font-weight: bold;
        }
 
        p {
            margin-bottom: 1em;
        }
    </style>
